## Arabic-Name Resolution Playbook

For Arabic targets, run **all** of these variants through every search engine:

1. **Arabic script full name** in modern standard spelling.
2. **UNGEGN transliteration**: `Khaled` (not `Khaledh`), `Jasser` (not `Jasar`), `Hamzeh`, `Rajab`, `Sulaiman`, `Ghanem`, `Mabkhout` (not `Mabkhot`).
3. **Common anglicizations** (Omar/Umar, Ahmed/Ahmad, Mohamed/Mohammed/Muhammad).
4. **Patronymic + given + family**: `Ahmad Mousa Al-Atoum` → `Ahmad Mousa Atoum` → `Ahmad M. Atoum` → `Ahmad Atoum`.
5. **Reverse:** family + given → `Atoum, Ahmad Mousa`.
6. **Drop the `Al-` prefix** when the family name is well-known without it (`Atoum` for `Al-Atoum`).
7. **Try with and without diacritics** (ʿ, ḥ, ā, ī, ū).
8. **Try patronymic chain alone** (e.g., `Yumna Ahmad Atoum` on ORCID — found children through their own academic IDs this way).
9. **Try the Arabic name in Arabic search engines**: `جريدة الرأي`, `الجزيرة`, `العمون`, `خبرني`, `أمد`, `عربي بوست`.
10. **Run the name through Arabic search platforms**: Maktba (`مكتبة`), Hindawi, Shamaa, Mandumah, Dorar, Dorat Al-Maarifa, Alfaisal University thesis index.
